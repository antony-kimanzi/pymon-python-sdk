# PyMon Python SDK 🐍

Monitor your Python jobs with one decorator. Get instant alerts with full stack traces when they fail.

## Why PyMon?

- 🐍 **One decorator:** No complex setup, no YAML files, no infrastructure changes.
- 📋 **Stack traces in alerts:** Know exactly which line of code failed instantly.
- ⚡ **Async support:** Works perfectly with `async`/`await` using `@monitor_async`.
- 🛡️ **Non-blocking:** If the PyMon API goes down, your script will *never* crash.
- 🆓 **Free forever:** No credit card, no hidden limits.

## Installation

You can install the SDK directly via pip:

pip install pymon-sdk
